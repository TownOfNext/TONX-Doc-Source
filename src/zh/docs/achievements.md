本页记录自 v4.0.2 后加入的成就，收录 **203 项成就**，可通过对应职业的有效技能事件或游戏结算解锁。

## 查看与佩戴

通过游戏内的成就面板查看分类、稀有度、解锁状态并选择称号。

| 指令 | 功能 |
| ---- | ---- |
| `/cmd ach [成就编号]` | 查看指定成就详情 |
| `/cmd achid` | 查看自己的成就列表 |
| `/cmd wach [成就编号]` | 在大厅佩戴已解锁的成就称号 |
| `/cmd wach 0` | 移除成就称号 |

成就由房主记录，需要有效的好友代码。自由练习不记录成就。
