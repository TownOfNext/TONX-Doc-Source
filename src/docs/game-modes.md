---
title: 游戏模式
---

TONX 内置了多种游戏模式，房主可以在大厅的「游戏模式」选项中进行切换。当前共支持以下三种模式：

- [标准模式](#标准模式standard)
- [个人竞技模式](#个人竞技模式solokombat)
- [角色抽取模式](#角色抽取模式roledraft)

## 标准模式

标准模式是 TONX 默认的游戏模式，所有职业、附加职业以及常规游戏设置都依据大厅中的选项进行分配。

在该模式下，房主可以自由开启或关闭任意职业与附加职业，并由系统根据设置自动分配阵营与数量。除此之外，标准模式没有额外的特殊规则，玩法与原版 Among Us 的扩展一致。

## 个人竞技模式

个人竞技模式下不会分配任何职业，所有玩家都成为「挑战者」，并拥有自己的血量（HP）。玩家可以使用击杀键对其他玩家造成伤害，游戏结束时击杀数（积分）最高的玩家获胜。

### 选项设置

| 选项 | 说明 |
| --- | --- |
| 游戏时长 | 整场比赛的持续时间（秒） |
| 默认血量 | 玩家初始拥有的血量 |
| 默认攻击力 | 每次攻击造成的伤害 |
| 回复冷却 | 玩家停止受击后，开始回复血量所需的等待时间 |
| 每秒回复量 | 每秒自动回复的血量 |
| 复活等待时间 | 玩家被击杀后，复活前的等待时间 |
| 击杀奖励倍率 | 击杀其他玩家时获得的血量奖励倍率 |
| 攻击冷却 | 使用击杀键的冷却时间 |

### 玩家面板显示

在任务面板中，玩家可以实时看到自己的攻击力、防御力与每秒回复量，以及当前所有玩家的积分排名。

## 轮抽选角

轮抽选角模式是 TONX 独特的角色选取玩法。游戏开始后，所有玩家会在一次会议中依次抽取自己的职业，而非由系统直接分配。

### 抽取流程

1. 游戏开始时会自动召开一次「选角会议」。
2. 系统会按座位顺序轮流让每位玩家从若干个随机职业中进行选取。
3. 每位玩家拥有固定的可选职业数量（由房主设置），并在限定时间内完成选择。
4. 若玩家超时未选，系统会自动为其随机抽取一个职业。
5. 全部玩家选择完毕后，会议结束，游戏正式开始。

### 选项设置

| 选项 | 说明 |
| --- | --- |
| 可选职业数量 | 每位玩家每轮看到的随机职业选项个数 |
| 选角时间 | 每位玩家进行选择的限时（秒） |
| 显示玩家选择 | 是否在公屏显示其他玩家所选的职业 |

### 指令

- `/cmd ch [编号]`：从当前可选职业中选择指定编号的职业（编号从 1 开始）
- `/cmd ch`：随机选择当前可选职业中的一个
